# Клубиум — серверная школьная платформа

Приложение на FastAPI + SQLite с электронной посещаемостью, кружками, портфолио, ролями, отчётами, расписанием, API для мобильного приложения и PWA-манифестом. Система без демонстрационных учеников, учителей и кружков.

## Быстрый запуск

```bash
# Windows: запустить start.bat
# Linux:
bash start.sh
```

Сайт: `http://127.0.0.1:8000`. Интерактивная API-документация `/api/docs`.

При первом запуске создаётся только **один главный администратор — `AzraelLone`**. Его временный случайный пароль создаётся на сервере, **не вшит** в проект. После входа его нужно сменить. Не добавляйте папку `instance` в GitHub.

## Удалить старые аккаунты при обновлении

Остановите сервер, перейдите в `clubium-server` и выполните `python keep_only_azrael.py --apply`. Скрипт сделает приватную резервную копию SQLite и удалит из базы все учётные записи, кроме `AzraelLone`. Удаляются также логины учителей/учеников/родителей; существующие школьные записи сохранятся с пустыми ссылками на удалённые учётные записи. Для просмотра списка до удаления: `python keep_only_azrael.py`.

## Данные и сохранность

SQLite: `instance/smartclub.sqlite3`. Ключ сеансов и вложения: `instance`. Для размещения в облаке используйте **постоянный диск**, HTTPS и регулярные резервные копии. Данные пользователей не попадут в репозиторий из-за `.gitignore`; всё равно проверяйте `git status` перед отправкой.

## Роли

Администратор управляет аккаунтами/кружками/учащимися. Учитель ведёт свои кружки и скачивает их отчёты. Ученик видит только **Главная, Кружки, Учащиеся, Посещаемость, Расписание, Портфолио** и не может скачать отчёт через сайт или API.

## Для Render

Blueprint в `../render.yaml` использует Docker и **платный постоянный диск** (`/var/data`), чтобы база не исчезла при перезапуске. Для первого запуска можно задать только `SMARTCLUB_OWNER_INITIAL_PASSWORD` (не менее 12 символов) в секретных переменных сервера. Переходите на продакшн только после правового и технического аудита.
